# Divide, Conquer, and Greedy Algorithms

A Java assignment created for Project 2 in my Year 2, Semester 1 Linear Data
Structures and Algorithms module.

This project contains implementations and exercise skeletons for divide-and-
conquer algorithms, greedy algorithms, sorting, and Huffman coding.

## Topics covered

- Fibonacci numbers and binary search
- Tower of Hanoi
- Merge sort and quick sort
- Activity selection
- Making change with a greedy algorithm
- Binary heaps and Huffman coding

## Java files

- `DivideAndConquer.java` - Fibonacci, binary search, and Tower of Hanoi
- `MergeSort.java` - merge sort
- `QuickSort.java` - quick sort
- `Greedy.java` - activity selection and making change
- `Activity.java` - activity data used by the greedy algorithm
- `BinaryTrie.java` - nodes for a Huffman coding trie
- `HeapOfBinaryTries.java` - min-heap of Huffman tries
- `Huffman.java` - Huffman encoding and decoding

## Running

The source files use the `assignment2` Java package. Open the project in a Java
IDE and run the `main` method in the class you want to test.
